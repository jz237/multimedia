## Media storage

Upload new masters to the `jez237-site-media` R2 bucket under `multimedia/<slug>/`, verify public SHA-256 checksums, and update `catalog.json` and `media-r2-manifest.json`. Do not commit MP4 files. The source of truth is `https://media.jez237.com/`.

GitHub Pages restores checksum-pinned, deployment-only copies to preserve old direct MP4 links. This is a deliberate compatibility exception; neither source repository stores those binaries.
